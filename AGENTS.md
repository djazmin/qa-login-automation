
# Project Instructions — QA Login Automation

## Project goal
Build a maintainable login test automation project using
Python, Playwright, and pytest.

## Technical rules
- Use Python 3.12 or a compatible project interpreter.
- Use pytest to run automated tests.
- Use Playwright's synchronous Python API.
- Prefer accessible locators and stable selectors.
- Use explicit assertions to validate application behavior.
- Avoid fixed sleeps when Playwright's auto-waiting is sufficient.
- Keep test cases readable and focused on one behavior.
- Never hardcode real credentials, API keys, or secrets.
- Do not add dependencies without explaining why.

## AI collaboration rules
- Explain proposed changes before making significant modifications.
- Do not invent test results; run tests when possible.
- Report any tests that were not executed.
- Explain failures and suggest the smallest appropriate fix.
- Do not mark a task complete without verification.

## Git rules
- Never commit secrets or the virtual environment.
- Keep commits small and describe their purpose clearly.
- Do not push changes without the user's approval.
